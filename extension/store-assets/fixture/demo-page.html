Getting started

Set up a workspace, create your first project and connect a client in about five minutes.

Before you begin, create a personal access token. Every client authenticates with one, and it is shown only once.

Create a token

1. Create a workspace

A workspace groups projects and the people who can see them. Pick a short name; you can rename it later without breaking any links. 

example workspace create "Design review"
example project add "Mobile app" --workspace "Design review"

2. Connect a client

Paste the token into the client's settings and press Test connection. A green check means the client can reach the workspace.

Setting Where Default
Workspace address Client settings Filled in for you
Access token Client settings —
Retention Project page 30 days

3. Share your first item

Every item gets a private link. Anyone who has the link can view it; nobody else can find it.
